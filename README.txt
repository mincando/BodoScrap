보도자료 → 네이버 뉴스 보도 목록 (HTML + JS)

브라우저는 보안 정책(CORS) 때문에 index.html 을 그냥 열어서는 다른 사이트(부처 홈페이지, 네이버)를
읽을 수 없습니다. 아래 두 방법 중 하나로 실행하세요. 화면과 기능은 같습니다.

[방법 1] 크롬/엣지 확장프로그램 (설치 프로그램 없음)
  1. 크롬 주소창에 chrome://extensions  (엣지는 edge://extensions) 입력
  2. 오른쪽 위 '개발자 모드' 켜기
  3. '압축해제된 확장 프로그램을 로드합니다' → 이 폴더 선택
  4. 툴바의 퍼즐 아이콘 → '보도자료 뉴스 추적기' 클릭 → 새 탭에서 도구가 열림

[방법 2] Node.js (18 이상)
  이 폴더에서  node server.js  실행 (또는 실행.bat 더블클릭)
  → 브라우저에서 http://localhost:8765 가 열림

파일
  index.html   화면
  app.js       수집·파싱 로직 전체
  manifest.json, background.js   확장프로그램용
  server.js    Node 실행용 (페이지 제공 + 외부 페이지 중계만 담당)
